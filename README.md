# Spotify Dashboard 🎵

This project is a **Spotify Data Dashboard** built to analyze and visualize the **Spotify Top 50 - Global** dataset.

## 📂 Project Structure
- **spotify-top-50-world.csv** → Dataset used for analysis  
- **Spotify Dashboard.pbix** → Power BI dashboard file  
- **Recording 2025-09-27 144507.mp4** → Screen recording/demo of the dashboard  
- **bg/** & **Icons/** → Assets used in the dashboard design  

## 📊 Features
- Interactive visualizations of top tracks  
- Artist and genre-wise analysis  
- Popularity trends and track comparisons  

## ▶️ How to Use
1. Open the `Spotify Dashboard.pbix` file in **Power BI Desktop**  
2. Explore the interactive dashboard  
3. (Optional) Play the screen recording to see a quick walkthrough  

## 📌 Notes
This project was created as a personal learning exercise to practice **data visualization** and **dashboard building** in Power BI.
